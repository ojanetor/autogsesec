# Project Charter — AutoGSESec

**Working Title:** AutoGSESec — Autonomous GSE Cybersecurity Tabletop Exercise Platform

**Problem:** No purpose-built cybersecurity training tool exists for professionals securing autonomous ground service equipment in U.S. aviation critical infrastructure.

**Intended Artifact:** Web-based tabletop exercise platform with scenario delivery, scoring engine, and after-action report generation.

**Users:** Autonomous vehicle operators, GSE engineers, airport security managers, aviation cybersecurity professionals, safety and systems professionals.

**Scope In:**
- 3 scenario modules mapped to MITRE ATT&CK for ICS tactics
- Rule-based scoring engine against NIST SP 800-82 controls
- After-action report generator with implementation timelines
- Public URL deployment

**Scope Out:**
- IRB primary research
- Mobile application
- Real-time vehicle integration
- Proprietary operational data
- Machine learning components

**Minimum Viable Artifact:** 3 working scenarios with scoring and after-action reports deployed to a public URL.

**Success Criteria:**
- 3 functional scenario modules
- 100% report generation on completed sessions
- 95% uptime during testing
- 3 peer reviewers complete 2 scenarios each unassisted
- Under 3-second response latency
